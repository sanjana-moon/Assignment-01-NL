# Assignment1 – Problem Solving with TypeScript & OOP

This repository contains my solutions for **Module 4: Assignment 1** of the Apollo Level 2 Web Development course.

The assignment focuses on strengthening my understanding of TypeScript fundamentals, problem-solving techniques, generics, and Object-Oriented Programming (OOP).

## Technologies Used

- TypeScript
- Object-Oriented Programming (OOP)
- Asynchronous JavaScript (Promises)

## Assignment Contents

### Problem Solving (`solutions.ts`)

The file contains solutions to all 8 problems covering:

1. Optional and default parameters
2. Union types and type narrowing
3. Readonly tuples
4. Generics and rest parameters
5. Interfaces and array filtering
6. Generics with `keyof` constraints
7. Classes, inheritance, and access modifiers
8. Asynchronous programming with Promises
